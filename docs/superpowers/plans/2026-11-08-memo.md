# 메모(검토 주석) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** HWPX 문서에 한글 2024와 호환되는 메모를 넣고·보고·고치고·지울 수 있게 한다 — 엔진 API 3종 + 쪽 오른쪽 여백 풍선 오버레이 + 검토 리본 메모 그룹.

**Architecture:** 엔진(Rust)은 기존 하이퍼링크의 범위 필드 삽입·제거 경로를 일반화해 `FieldType::Memo` 필드를 만들고 `getMemoList` JSON으로 목록을 준다. 스튜디오(TS)는 그 목록과 `getSelectionRects*`로 앵커 사각형을 구해 `#scroll-content` 위 오버레이 레이어에 쪽별 여백 띠·풍선·안내선을 그린다. 변경은 모두 `executeOperation({kind:'snapshot'})`으로 실행 취소에 들어간다.

**Tech Stack:** Rust(wasm-bindgen, serde) · wasm-pack · vanilla TypeScript + Vite · node:test

**Spec:** `docs/superpowers/specs/2026-11-08-memo-design.md`

## Global Constraints

- 포크 밖 사용자에게 보이는 문자열(코드·i18n·문서)에 특정 조직 이름을 넣지 않는다.
- 메모 본문 `memo_paragraphs`는 **항상 1문단 이상** — 비면 HWPX `subList`가 빠져 한글이 파일을 열지 못한다(spec §2 금지, serializer/hwpx/field.rs:312 주석).
- 새 메모의 파일 형상은 한글 실측과 같다: `command = "MEMO/65535/<index>/<메모별 난수>/<문서 공통 난수>/<author>/\;;"`, parameters 7종(Prop=0, Command, ID=`memo<index>`, Number, Author, MemoShapeIDRef=`65535`, CreateDateTime=ISO 8601 UTC `YYYY-MM-DDTHH:MM:SSZ`), `fieldid`(=`instance_id`) **623209829**, `editable="1"`, header에 memoPr 추가 없음.
- 풍선 색 상수: 채움 `#CBFF99`, 활성 `#FDBCDD`, 선 `#A9A9A9`, 띠 폭 15591 HWPUNIT(=15591/75 px·zoom).
- 새 WasmBridge 공개 메서드 이름이 `insert|set|remove…`로 시작하면 `src/core/mutation-method-registry.ts`의 `MUTATING_METHODS`에 등록한다(`tests/mutation-routing-guard.test.ts`).
- 스튜디오 시험은 `node --test`가 `.ts`를 그대로 읽는다 — 시험에서 import하는 모듈은 `@/` 별칭 없이 **상대 경로 + `.ts` 확장자**만 쓴다.
- 엔진 시험: `cargo test --lib <필터>`. wasm 빌드: `wasm-pack build --target web --release --out-dir pkg`(약 10분, `cargo test`와 target 잠금을 공유하므로 동시에 돌리지 않는다).
- 스튜디오 빌드는 PowerShell에서만: `$env:RHWP_BASE='/hwpx/'; $env:RHWP_DISABLE_EXTERNAL_WEBFONTS='1'; tools\node20\node.exe …\tsc` 뒤 `…\vite.js build`.
- 커밋 메시지 끝: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. **메모가 걸린 글자를 사용자가 지울 때** — 범위가 0이 되면 메모 필드가 고아가 되거나 저장 파일이 깨지면 안 된다. 기대: 메모도 함께 사라지고 상태줄 한 줄 안내(Task 9 시험).
2. **.hwp 문서를 열어 .hwp로 저장** — 내용을 못 읽은 메모가 있으면 조용히 사라지면 안 된다. 기대: 저장 전 경고 + [HWPX로 저장](Task 11 시험).
3. **쪽을 두 단으로 나란히 보기 + 폭 맞춤** — 띠가 켜졌을 때 오른쪽 쪽이 잘리거나 띠가 다음 쪽을 덮으면 안 된다. 기대: 쪽마다 자기 띠, 폭 맞춤은 띠 포함(Task 6 시험).
4. **아주 긴 메모(수백 자)와 한 줄에 메모 여러 개** — 풍선이 겹치거나 쪽 아래로 넘쳐 안 보이면 안 된다. 기대: 아래로 밀어 쌓고 쪽 높이를 넘으면 띠가 늘어난다(Task 5 적층 시험).
5. **환경 설정 사용자 이름이 비어 있을 때 메모 넣기** — 작성자가 빈 문자열로 저장되면 한글에서 이름 없는 메모가 된다. 기대: 환경 설정 열기 안내 후 넣지 않음(Task 8 시험).
